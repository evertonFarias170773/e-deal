# Organização

```text
docs/
├── architecture/
├── business/
├── maestro/
├── technical/
├── history/
└── migrations/
```

- `architecture`: arquitetura oficial e referência histórica;
- `business`: fluxos e regras de módulos;
- `maestro`: produto, conhecimento, segurança e status;
- `technical`: Matriz, permissões e UX/UI;
- `history`: changelog, decisões e registros antigos;
- `migrations`: scripts históricos ou propostas, sem autorização automática.
